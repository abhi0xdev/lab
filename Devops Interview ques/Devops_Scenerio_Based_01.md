What would you do if traffic spikes 5x on AWS and users start getting 502 errors while CPU usage is normal?
A 502 error usually indicates the load balancer cannot get a valid response from backend targets. I would first check the Application Load Balancer target group health and verify whether instances are failing health checks or timing out. Then I would investigate backend dependencies like the database, especially RDS connection limits and slow queries. This works by identifying bottlenecks outside CPU usage such as connection exhaustion or application thread limits. It is used to diagnose architecture-level issues rather than simply scaling compute. A limitation is that scaling instances alone will not fix database or connection pool limits. In real scenarios, tuning connection pools, adding read replicas, and implementing temporary rate limiting can stabilize the system.

How would you troubleshoot a sudden increase in GitLab CI pipeline duration from 8 minutes to 25 minutes?
I would first analyze which stages are consuming the most time by reviewing pipeline job metrics. If new security scans or heavy tasks were added, I would restructure the pipeline using DAG parallel execution to run jobs simultaneously. This works by reducing sequential dependencies and optimizing build time. It is used to maintain developer productivity while keeping quality checks in place. A limitation is increased infrastructure cost when many jobs run in parallel. In real scenarios, caching dependencies, separating fast pipelines from full validation pipelines, and using autoscaling runners significantly improve performance.

How would you respond if a Terraform apply with incorrect variables replaced a critical production resource?
The first step is to immediately stop further Terraform runs and lock the state to prevent additional changes. I would assess the damage and restore infrastructure from backups, snapshots, or previously known good state. This works by stabilizing the environment before attempting recovery actions. It is used to minimize downtime and avoid cascading failures. A limitation is that some resources cannot be restored instantly depending on service constraints. In real scenarios, implementing CI-only Terraform applies, enabling state locking, adding prevent_destroy rules, and enforcing approval gates prevents such incidents.
